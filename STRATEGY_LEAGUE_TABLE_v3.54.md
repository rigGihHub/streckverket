# Strategy League Table v3.54

## Syfte
Jämför prospektivt frysta systemstrategier på samma kuponger, i stället för att jämföra råa snitt från olika historiska urval.

## Metod
- Ett A–B-möte innehåller bara kuponger där både A och B finns frysta före spelstopp och komplett facit finns.
- Minst 20 gemensamma kuponger krävs innan mötet blir granskningsbart.
- Kupongnivån ger A-vinst, oavgjort eller B-vinst baserat på antal täckta matchutfall.
- Ett granskningsbart par ger 3 ligapoäng till den strategi som vinner fler av de gemensamma kupongerna, eller 1–1 vid lika antal vinster.
- Snittträffar, 13-rättstäckning och snittrader visas som kontext men används inte för att fabricera ett resultat före datatröskeln.

## Alias-proveniens
v3.53 tog korrekt bort identiska system men tappade då ibland att flera strategier hade producerat samma urval. Från v3.54 sparas alias på samma fysiska system. Ett identiskt system är ett verkligt oavgjort strategimöte, inte frånvaro. Äldre historik backfylls inte utöver den explicit sparade faktiska strategin för ORIGINAL.

## Begränsningar
Detta är deskriptiv prospektiv historik. 20 kuponger är en produkttröskel, inte ett formellt statistiskt bevis. Ingen ROI, faktisk utdelning eller edge kan härledas från tabellen.
