# Streckverket v3.73 – Kupongens nyckelbeslut

Normalvyn lyfter högst tre beslut som redan finns i systemet:

- **Viktigaste spiken**: systemets spik med högst modellstöd.
- **Viktigaste garderingen**: den garderade match där modellen är mest öppen.
- **Matchen som kan fälla många**: visas bara när folkets favorit är minst fem procentenheter mer streckad än modellens sannolikhet.

Detta är ett presentationslager. Det ändrar inte modell, sannolikheter, strategi eller systemtecken.

Formuleringarna ska beskriva befintliga data och får inte framställa en modellavvikelse som bevisad edge eller garanterad skräll.
