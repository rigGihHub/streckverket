# Streckverket v3.71 – Analysis Change Report

Efter **Uppdatera analysen nu** jämför normalvyn analysen före och efter uppdateringen.

Den visar först om systemtecknen ändrades eller är oförändrade. Vid behov kan användaren öppna detaljer med ändrade matcher, odds, förbättrat startelvsunderlag och ändrad spelklarhetsstatus.

Jämförelsen är diagnostisk. Den hävdar inte att en förändring gör systemet bättre och ändrar inte modell, sannolikheter eller strategimotor.
